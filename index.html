🔬 电力市场时序预测 + Stable Learning 效果不理想的 3 大排查方向

  1. 勿在原始滞后特征上硬做样本去相关：时间序列步长 yt-1 … yt-L 天然强自相关，经典 IID 样本重加权（DWR/SRDO）会抹掉时序动态规律。解法：转移到低维隐层表征（Patch/Bottleneck）或仅对外生变量（气象/节假日）做去混杂。
  2. 检查权重塌缩（ESS 暴跌）：窗口 96 × 10 变量 = 960 维高度共线特征，优化样本权重极易病态。务必打印权重最大/最小值及有效样本量（ESS）诊断。
  3. 先剥离幅值非平稳性，再做稳定学习：电力负荷/电价存在剧烈均值方差漂移，需先叠加 RevIN / 趋势-季节分解去掉一二阶统计漂移，再用 Stable Learning 处理跨季节/极端天气的伪相关漂移（可结合 Chronos / Timer 冲击 CCF-A/B 或 IEEE TKDE）。
